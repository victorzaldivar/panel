# panel

Aloja una unica pagina cifrada: un panel personal de entrenamiento
protegido con AES-256-GCM y clave derivada por PBKDF2-HMAC-SHA256
(600.000 iteraciones). Se descifra en el navegador de quien conoce
la contrasena.

Este repositorio no contiene datos en claro ni credenciales. Se
regenera entero cada dia desde un repositorio privado.
